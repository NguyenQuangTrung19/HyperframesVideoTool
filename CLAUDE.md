# Code map — Auto-Create-Video

Bản đồ tĩnh các file code hay đụng, để khỏi đào file-by-file. Codebase ~50 file/~10k dòng TS; repo chủ yếu là **content** (`video/`, `podcast/`), code tương đối ổn định. Quy ước workflow/nội dung nằm ở auto-memory, KHÔNG lặp lại ở đây.

## Pipeline /create-video (motion-graphic)
`npm run pipeline -- <dir>/script.json` → `src/cli.ts` (entry mỏng, load `.env.local`) → **`src/pipeline.ts`** (orchestrator 9 bước: validate → TTS → align → image → concat+SFX → compose HTML → render).
- **outputDir = thư mục chứa script.json.** Override ảnh tra ở `<outputDir>/images/<sceneId>.<ext>`. Layout chuẩn: script.json + voice/ + video.mp4 ở `video/output/<slug>/`; .txt + images-plan.json + ảnh thô ở `video/input/<slug>/`.
- Voice cache theo existence: `<outputDir>/voice/full.mp3` + `full-words.json` (TTS+align, đắt API) — xóa để ép làm lại. `scene-*.mp3` LUÔN cắt lại từ full.mp3 → sửa logic cắt rồi render lại KHÔNG tốn quota TTS.
- **Cắt scene audio = phân hoạch liền mạch, cắt giữa silence** (2026-07-09, `detectSilences()` + `pickSceneCut()`). ĐỪNG quay lại cắt `startWord.start → endWord.end`: Whisper kết thúc từ sớm + bắt đầu từ kế muộn, nên khoảng 0,4–0,8s giữa 2 scene (chứa đuôi phụ âm VN + onset từ sau) bị vứt → **mất âm cuối mỗi scene**. Scene N kết thúc đúng chỗ scene N+1 bắt đầu; điểm cắt đặt giữa khoảng lặng thật (`silencedetect -45dB/0.06`), Whisper trôi mốc thì nới tìm ±0,6s (`CUT_SNAP_SEC`). Verify không cần render: đo `max_volume` ±40ms quanh mỗi điểm cắt, phải ≤ -35 dB.
- **Nhạc nền = thả file vào `assets/music/`, KHÔNG cần config** (2026-07-31): step 6 tự random 1 track, loop cho đủ độ dài, ducking ~6 dB dưới giọng (`sidechaincompress`). Thư mục rỗng → không nhạc (mặc định hiện tại). `VIDEO_BG_MUSIC=""` tắt, `=<tên|path>` ghim 1 bài, `VIDEO_BG_MUSIC_VOLUME` (0.10, trần 0.15). Bed chain PHẢI mono — `channel_layouts=stereo` khiến ffmpeg rematrix mono→stereo giảm 3 dB, cả giọng bị nhỏ đi. Đừng tăng ratio ducking: SCENE_GAP_SEC chỉ 0,3s < release nên duck sâu không bao giờ hồi, nhạc coi như tắt. Align caption chạy step 4 trên `voice/full.mp3` sạch nên nhạc KHÔNG ảnh hưởng caption. ⚠️ `assets/beat/` có nhạc thương mại (seeyouagain/vetmua) — đừng copy sang.
- **MỘT nền cho cả video** (v3, 2026-07-27): `.shell-bg` = slate-2 phẳng + lưới 46px/230px + `.shell-vignette`, port từ `Stage.tsx` bên Remotion. Mọi `.bg.gradient-*` và `.layout-outro` đều `background:none` — nền là shell, không template nào tự vẽ nền riêng. Màu lấy từ thang 12 bậc ở `:root` (slate / **sky** / amber — brand đổi sang xanh dương mây trời 2026-07-27): **bậc 9 = mảng màu (đừng đặt chữ trắng lên, 3.98:1), bậc 10 = nền nút có chữ trắng, bậc 11 = chữ màu, 12 = ink**; bóng ám sắc slate, KHÔNG đen thuần. Đã bỏ hẳn `.bg-deck-blur` (ảnh blur làm nền → ra bùn, gold trên đó chỉ 1.8:1) và `.bg-grade-overlay` ở engagement-question (radial đen phủ nền sáng → `#9a9792`).
- **CHỈ hook full-bleed; ảnh body vào KHUNG CỐ ĐỊNH** (2026-07-27): pipeline đo tỉ lệ ảnh staged (`image-dims.ts`) → `sceneImageAspect`, nhưng tỉ lệ đó CHỈ chọn bucket, không set kích thước (`shapeOf()` trong `html-composer.ts`; `--ar`/`aspect-ratio` không còn xuất hiện trong markup). 3 slot: ngang `>1.22` → 920×613, vuông `0.88–1.22` → 660×660, dọc `<0.88` → 560×730; ảnh `cover` vào slot với `background-position: 50% 38%`. Verify bằng `npx tsx scripts/_design-shots.ts <script.json> <outDir>` (chụp + đo mọi cảnh, khỏi render mp4); mọi khối nằm trong header 292 → 1500. ## Scripts (npm run)
- `images:stage -- <txt>` — `scripts/stage-planned-images.ts`: verify + copy ảnh plan → `output/<slug>/images/`; chạy combine trước.
- `images:combine -- <dir>` — `scripts/combine-split-images.ts`: ghép `<stem>-1`+`<stem>-2` → `<stem>.png` (split-frame).
- `validate -- <script.json>` — `_validate-script.ts` (repo ROOT, không phải scripts/): gate BẮT BUỘC trước mọi render. Chặn schema (zod) + nhịp (9:16: ≤170 từ tổng, ≤16 từ/cảnh, hook ≤12; 16:9 nới riêng). Exit 1 = đừng render.
- `video-queue -- list|set` — `scripts/video-queue.ts`: driver `video/input/queue.xlsx`.
- `podcast-queue` — `scripts/podcast-queue.ts`. `render:check` — `scripts/verify-render.ts`.
- `npx tsx scripts/_design-shots.ts <script.json> <outDir>` — chụp + ĐO từng cảnh bằng puppeteer từ script.json thật; dùng thay vì render mp4 khi sửa CSS/composer.
- `npx tsx scripts/_motion-preview.ts <script.json> <out.mp4> [giây] [fps]` — seek timeline từng frame → mp4 (không audio, không TTS); dùng khi sửa `animations.js`.
- `patch:hf` — `scripts/patch-hyperframes-gpu.ts`: vá `node_modules/hyperframes/dist/cli.js` cho `--use-angle` đọc env `HF_ANGLE_BACKEND`. Chạy tự động qua `postinstall` (npm install ghi đè node_modules → mất patch).

## Tốc độ render — GPU vs SwiftShader
Nút thắt KHÔNG phải encode/fps/workers mà là raster: hyperframes hardcode `--use-angle=swiftshader` (CPU). `HF_ANGLE_BACKEND=d3d11` trong `.env.local` đẩy sang GPU (cần `patch:hf` đã chạy); bỏ env → về mặc định cũ. Đo lại cùng composition `man-united-nham-tyler-adams` (2212 frame, 1080×1920, quality high, Ryzen 5 5600H + Radeon iGPU): **515s (swiftshader, 4w) → 100s (d3d11, 4w) → 91s (d3d11, 6w)**; SSIM giữa bản CPU và GPU 0,997, khung hình nhìn không phân biệt được. Đối chiếu: x264 preset slow crf15 chỉ chiếm ~32s (giờ là phần lớn nhất còn lại), nên hạ `RENDER_QUALITY` mới có ý nghĩa sau khi đã bật GPU.

## Render thật (batch)
`npm run images:stage -- <input>/<slug>.txt` → `npm run pipeline -- <output>/<slug>/script.json` ở background từ main loop; verify mp4 bằng ffprobe (đừng tin exit code).
