1. Mở https://grok.com trên **`6` tab cùng lúc** → Imagine, aspect ratio **9:16**.
2. Copy từng block prompt phía trên, paste vào tab tương ứng, bấm generate **đồng loạt rồi mới chờ tất cả xong**.
3. Save mỗi ảnh vào cùng folder với .txt (`video/input/nhan-dinh-iran-vs-new-zealand-wc-2026/`) với stem đúng như file đã ghi (`hook`, `prediction`, `taremi`, `wood`, `coach-iran`, `coach-nz`).
   - **Extension nào cũng được:** `.png` / `.jpg` / `.jpeg` / `.webp`. Grok export `.jpg` thì giữ nguyên, không cần đổi đuôi.
4. Khi đủ `6` ảnh, chạy: `/create-video video/input/nhan-dinh-iran-vs-new-zealand-wc-2026/nhan-dinh-iran-vs-new-zealand-wc-2026.txt`
