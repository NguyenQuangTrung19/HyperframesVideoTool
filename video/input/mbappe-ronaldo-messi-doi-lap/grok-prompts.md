1. Mở https://grok.com trên **9 tab cùng lúc** → Imagine, aspect ratio **9:16**.
2. Copy từng block prompt phía trên, paste vào tab tương ứng, bấm generate **đồng loạt rồi mới chờ tất cả xong**.
3. Save mỗi ảnh vào cùng folder với .txt (`video/input/mbappe-ronaldo-messi-doi-lap/`) với stem đúng như file đã ghi (`hook`, `messi-ronaldo`, ...).
   - **Extension nào cũng được:** `.png` / `.jpg` / `.jpeg` / `.webp`. Grok export `.jpg` thì giữ nguyên, không cần đổi đuôi.
4. Khi đủ 9 ảnh, chạy: `/create-video video/input/mbappe-ronaldo-messi-doi-lap/mbappe-ronaldo-messi-doi-lap.txt`
