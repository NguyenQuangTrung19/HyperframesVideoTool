## Tiếp theo

⚡ **Tip — gen ảnh song song để tiết kiệm thời gian.** Mở `7` tab grok.com cùng lúc, paste prompt vào từng tab, bấm generate đồng loạt rồi mới chờ. Cắt thời gian từ ~10-15 phút xuống ~3-5 phút.

1. Mở https://grok.com trên **`7` tab cùng lúc** → Imagine, aspect ratio **9:16**.
2. Copy từng block prompt phía trên, paste vào tab tương ứng, bấm generate **đồng loạt rồi mới chờ tất cả xong**.
3. Save mỗi ảnh vào cùng folder với .txt (`video/input/ancelotti-va-brazil-giac-mo-world-cup/`) với stem đúng như file đã ghi (`hook`, `neymar-fitness`, ...).
   - **Extension nào cũng được:** `.png` / `.jpg` / `.jpeg` / `.webp`. Grok export `.jpg` thì giữ nguyên, không cần đổi đuôi.
4. Khi đủ `7` ảnh, chạy: `/create-video video/input/ancelotti-va-brazil-giac-mo-world-cup/ancelotti-va-brazil-giac-mo-world-cup.txt`
