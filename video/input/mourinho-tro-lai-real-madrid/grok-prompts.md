1. Mở https://grok.com trên **`10` tab cùng lúc** → Imagine, aspect ratio **9:16**.
2. Copy từng block prompt phía trên, paste vào tab tương ứng, bấm generate **đồng loạt rồi mới chờ tất cả xong**.
3. Save mỗi ảnh vào cùng folder với .txt (`video/input/mourinho-tro-lai-real-madrid/`) với stem đúng như file đã ghi (`hook`, `perez-win`, ...).
   - **Extension nào cũng được:** `.png` / `.jpg` / `.jpeg` / `.webp`. Grok export `.jpg` thì giữ nguyên, không cần đổi đuôi.
4. Khi đủ `10` ảnh, chạy: `/create-video video/input/mourinho-tro-lai-real-madrid/mourinho-tro-lai-real-madrid.txt`
