1. Mở https://grok.com trên **9 tab cùng lúc** → Imagine, aspect ratio **9:16**.
2. Copy từng block prompt phía trên, paste vào tab tương ứng, bấm generate **đồng loạt rồi mới chờ tất cả xong**.
3. Save mỗi ảnh vào cùng folder với .txt (`video/input/mbappe-phong-ngu-tuyen-phap-wc-2026/`) với stem đúng như file đã ghi (`hook`, `the-promise`, …, `senegal-opener-1`, `senegal-opener-2`).

4. Khi đủ ảnh, chạy: `/create-video video/input/mbappe-phong-ngu-tuyen-phap-wc-2026/mbappe-phong-ngu-tuyen-phap-wc-2026.txt`
