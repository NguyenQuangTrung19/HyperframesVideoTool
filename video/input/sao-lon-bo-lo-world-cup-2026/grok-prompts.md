## Tiếp theo

⚡ **Tip — gen ảnh song song để tiết kiệm thời gian.** Mở các tab grok.com cùng lúc, paste prompt vào từng tab, bấm generate đồng loạt rồi mới chờ. Cắt thời gian từ ~25 phút xuống ~4 phút.

1. Mở https://grok.com trên **`10` tab cùng lúc** → Imagine, aspect ratio **9:16**.
2. Copy từng block prompt phía trên, paste vào tab tương ứng, bấm generate **đồng loạt rồi mới chờ tất cả xong**.
3. Save mỗi ảnh vào cùng folder với .txt (`video/input/sao-lon-bo-lo-world-cup-2026/`) với stem đúng như file đã ghi (`hook`, `palmer`, ...).
   - **Extension nào cũng được:** `.png` / `.jpg` / `.jpeg` / `.webp`. Grok export `.jpg` thì giữ nguyên, không cần đổi đuôi.
4. Khi đủ `10` ảnh, chạy: `/create-video video/input/sao-lon-bo-lo-world-cup-2026/sao-lon-bo-lo-world-cup-2026.txt`
