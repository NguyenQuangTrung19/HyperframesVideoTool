1. Mở https://grok.com trên **`7` tab cùng lúc** → Imagine, aspect ratio **9:16**.
2. Copy từng block prompt phía trên, paste vào tab tương ứng, bấm generate **đồng loạt rồi mới chờ tất cả xong**.
3. Save mỗi ảnh vào cùng folder với .txt (`video/input/tuyen-phap-thua-bo-bien-nga-chieu-sau-doi-hinh/`) với stem đúng như file đã ghi (`hook`, `young-cracks`, ...).
   - **Extension nào cũng được:** `.png` / `.jpg` / `.jpeg` / `.webp`. Grok export `.jpg` thì giữ nguyên, không cần đổi đuôi.
4. Khi đủ `7` ảnh, chạy: `/create-video video/input/tuyen-phap-thua-bo-bien-nga-chieu-sau-doi-hinh/tuyen-phap-thua-bo-bien-nga-chieu-sau-doi-hinh.txt`
