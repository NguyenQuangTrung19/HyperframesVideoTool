## Tiếp theo

⚡ **Tip — gen ảnh song song để tiết kiệm thời gian.** Mở `7` tab grok.com cùng lúc, paste prompt vào từng tab, bấm generate đồng loạt rồi mới chờ. Cắt thời gian từ ~10-15 phút (sequential) xuống ~3-5 phút (batch parallel).

1. Mở https://grok.com trên **`7` tab cùng lúc** → Imagine, aspect ratio **9:16**.
2. Copy từng block prompt phía trên (gồm `hook-1`, `hook-2`, và 5 scene còn lại), paste vào tab tương ứng, bấm generate **đồng loạt rồi mới chờ tất cả xong**.
3. Save mỗi ảnh vào cùng folder với .txt (`video/input/nhan-dinh-duc-vs-curacao-wc-2026/`) với stem đúng như file đã ghi (`hook-1`, `hook-2`, `star-musiala`, `star-woltemade`, `star-bacuna`, `coach-nagelsmann`, `coach-advocaat`).
   - **Extension nào cũng được:** `.png` / `.jpg` / `.jpeg` / `.webp`. Grok export `.jpg` thì giữ nguyên, không cần đổi đuôi.
   - `hook-1` + `hook-2` sẽ tự ghép thành `hook.png` lúc `npm run images:stage`. Muốn 1 ảnh sẵn thì gen prompt split-frame ở mục [1] rồi save thẳng `hook.png`.
4. Khi đủ ảnh, chạy: `/create-video video/input/nhan-dinh-duc-vs-curacao-wc-2026/nhan-dinh-duc-vs-curacao-wc-2026.txt`
