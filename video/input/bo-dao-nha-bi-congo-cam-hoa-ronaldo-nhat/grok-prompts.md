1. Mở https://grok.com trên **`15` tab cùng lúc** → Imagine, aspect ratio **9:16**.
2. Copy từng block prompt phía trên, paste vào tab tương ứng, bấm generate **đồng loạt rồi mới chờ tất cả xong**.
3. Save mỗi ảnh vào cùng folder với .txt (`video/input/bo-dao-nha-bi-congo-cam-hoa-ronaldo-nhat/`) với stem đúng như file đã ghi (`hook`, `neves`, `wissa`, ...).
   - **Extension nào cũng được:** `.png` / `.jpg` / `.jpeg` / `.webp`. Grok export `.jpg` thì giữ nguyên, không cần đổi đuôi.
4. Khi đủ `15` ảnh, chạy: `/create-video video/input/bo-dao-nha-bi-congo-cam-hoa-ronaldo-nhat/bo-dao-nha-bi-congo-cam-hoa-ronaldo-nhat.txt`
