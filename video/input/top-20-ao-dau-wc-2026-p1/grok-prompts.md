1. Mở https://grok.com trên **12 tab cùng lúc** → Imagine, aspect ratio **9:16**.
2. Copy từng block prompt phía trên, paste vào tab tương ứng, bấm generate **đồng loạt rồi mới chờ tất cả xong**.
3. Save mỗi ảnh vào cùng folder với .txt (`video/input/top-20-ao-dau-wc-2026-p1/`) với stem đúng như file đã ghi (`hook`, `kit-20`, ..., `kit-11`, `cta`).
   - **Extension nào cũng được:** `.png` / `.jpg` / `.jpeg` / `.webp` / `.avif`. Grok export `.jpg` hay `.avif` thì giữ nguyên, không cần đổi đuôi.
4. Khi đủ 12 ảnh, chạy: `/create-video video/input/top-20-ao-dau-wc-2026-p1/top-20-ao-dau-wc-2026-p1.txt`
