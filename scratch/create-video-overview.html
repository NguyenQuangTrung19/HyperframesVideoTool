Pipeline /create-video & 10 loại Scene

Skill chính build video motion-graphic 9:16 (1080×1920) cho kênh SportsForAllTV. Nội dung do AI viết, render deterministic bằng HyperFrames + HTML composer. Palette cream–green–gold. Dưới đây là toàn bộ pipeline và 10 template scene hệ thống hỗ trợ.

A. Luồng pipeline

Từ nguồn .txt → script.json → TTS + ảnh → render → mp4. 1 video = 5–20 scene (news 5–8, bio/history 10–15).

01
Nguồn .txt
URL (/read-rewrite) hoặc ghi chú (/refine-txt) hoặc .txt sạch + images-plan.json
→
02
Classify + density
Phân 11 content type. Đếm "distinct points" → quyết số scene. <3 điểm = bail
→
03
Viết script.json
Chọn template/scene, voiceText (phonetic rules), hook + engagement-question + outro bắt buộc. Zod validate
→
04
Stage ảnh
npm run images:stage — copy ảnh Grok manual vào output/images/
images:stage
→
05
TTS
AusyncLab (An Khôi, myna-2). Idempotent: bỏ qua scene đã có mp3
→
06
Render + mux
HTML→frame→ffmpeg, transitions + SFX + voice → video.mp4
npm run pipeline
Mỗi scene gồm: id · type (hook/body/outro) · voiceText · templateData (1 trong 10) · sfx? · imagePrompt?
Ràng buộc: scene[0]=hook · scene cuối=outro · 5–20 scene
